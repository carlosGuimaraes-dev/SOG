# Install Symphony

Use this skill when a repository owner wants to prepare a target repository to run under Symphony.

Core responsibilities:

- validate GitHub, Linear, Codex, and web-tooling readiness
- install the Symphony project contract
- install the required local skills
- support `attach` and `provision`
- leave clear next steps after setup
