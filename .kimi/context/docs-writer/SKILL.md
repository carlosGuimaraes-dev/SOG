# Skills Disponíveis — Docs Writer

Este arquivo lista as skills reutilizáveis à disposição deste agente.
Para usar uma skill, leia seu SKILL.md antes de redigir.

---

## Technical Documentation
**Use quando:** escrever README, CHANGELOG, docstrings, guias de uso ou documentar decisões.
**Arquivo:** `.kimi/skills/technical-documentation/SKILL.md`
**Prioridade:** ALTA

## API Documentation
**Use quando:** documentar endpoints, schemas, códigos de erro, autenticação ou criar coleções OpenAPI.
**Arquivo:** `.kimi/skills/api-documentation/SKILL.md`
**Prioridade:** ALTA

---

## Como usar uma skill

1. Antes de redigir, verifique se há uma skill relevante para o tipo de documentação
2. Leia o SKILL.md da skill com `ReadFile`
3. Use os templates e exemplos como base
4. Garanta que exemplos de código sejam executáveis
