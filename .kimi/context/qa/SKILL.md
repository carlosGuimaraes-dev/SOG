# Skills Disponíveis — QA Engineer

Este arquivo lista as skills reutilizáveis à disposição deste agente.
Para usar uma skill, leia seu SKILL.md antes de executar.

---

## QA Validation
**Use quando:** validar funcionalidade, classificar bugs por severidade, elaborar relatório de QA ou verificar regressão.
**Arquivo:** `.kimi/skills/qa-validation/SKILL.md`
**Prioridade:** ALTA

## Pytest Runner
**Use quando:** executar testes Python, filtrar por marcação, gerar cobertura ou debugar falhas de teste.
**Arquivo:** `.kimi/skills/pytest-runner/SKILL.md`
**Prioridade:** MÉDIA

## Frontend Test Runner
**Use quando:** executar testes de frontend com Vitest, filtrar suites ou gerar relatórios de cobertura.
**Arquivo:** `.kimi/skills/frontend-test-runner/SKILL.md`
**Prioridade:** MÉDIA

---

## Como usar uma skill

1. Antes de validar, verifique se há uma skill relevante nesta lista
2. Leia o SKILL.md da skill com `ReadFile`
3. Aplique os padrões e templates nos relatórios e execuções
4. Siga os checklists listados para não omitir etapas
