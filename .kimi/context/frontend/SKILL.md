# Skills Disponíveis — Frontend Engineer

Este arquivo lista as skills reutilizáveis à disposição deste agente.
Para usar uma skill, leia seu SKILL.md antes de implementar.

---

## React Vite Frontend
**Use quando:** criar páginas, componentes, hooks ou integrar com APIs REST no frontend React + Vite.
**Arquivo:** `.kimi/skills/react-vite-frontend/SKILL.md`
**Prioridade:** ALTA

## Tailwind shadcn/ui
**Use quando:** estilizar componentes, configurar tema, usar componentes shadcn/ui ou implementar dark mode.
**Arquivo:** `.kimi/skills/tailwind-shadcn/SKILL.md`
**Prioridade:** ALTA

## Frontend Testing
**Use quando:** escrever testes de componentes com Vitest e React Testing Library, mockar módulos ou testar hooks.
**Arquivo:** `.kimi/skills/frontend-testing/SKILL.md`
**Prioridade:** MÉDIA

## Frontend Accessibility
**Use quando:** revisar acessibilidade de componentes, adicionar ARIA, verificar contraste ou testar navegação por teclado.
**Arquivo:** `.kimi/skills/frontend-accessibility/SKILL.md`
**Prioridade:** MÉDIA

## Frontend Code Quality
**Use quando:** refatorar componentes, organizar imports, aplicar TypeScript strict ou melhorar legibilidade.
**Arquivo:** `.kimi/skills/frontend-code-quality/SKILL.md`
**Prioridade:** MÉDIA

## Frontend Test Runner
**Use quando:** executar testes frontend, filtrar suites, gerar relatórios de cobertura ou debugar falhas.
**Arquivo:** `.kimi/skills/frontend-test-runner/SKILL.md`
**Prioridade:** BAIXA

---

## Como usar uma skill

1. Antes de implementar, verifique se há uma skill relevante nesta lista
2. Leia o SKILL.md da skill com `ReadFile`
3. Aplique os padrões e exemplos no código que está escrevendo
4. Siga os anti-patterns listados para evitar armadilhas conhecidas
