# Skills Disponíveis — DevOps Engineer

Este arquivo lista as skills reutilizáveis à disposição deste agente.
Para usar uma skill, leia seu SKILL.md antes de implementar.

---

## Docker Compose Infra
**Use quando:** criar ou modificar Dockerfiles, docker-compose.yml, multi-stage builds, health checks ou networks.
**Arquivo:** `.kimi/skills/docker-compose-infra/SKILL.md`
**Prioridade:** ALTA

## Nginx Proxy
**Use quando:** configurar proxy reverso, SSL/TLS, rate limiting, load balancing ou SPA fallback.
**Arquivo:** `.kimi/skills/nginx-proxy/SKILL.md`
**Prioridade:** ALTA

## GitHub Actions CI
**Use quando:** criar pipelines CI/CD, workflows reutilizáveis, cache de dependências ou deploy automatizado.
**Arquivo:** `.kimi/skills/github-actions-ci/SKILL.md`
**Prioridade:** ALTA

## Como usar uma skill

1. Antes de implementar, verifique se há uma skill relevante nesta lista
2. Leia o SKILL.md da skill com `ReadFile`
3. Aplique os padrões e exemplos na infra que está configurando
4. Siga os anti-patterns listados para evitar armadilhas conhecidas
