# Context subtree for Codex

This subtree contains role-specific operating instructions.

For any role directory under `context/`:

1. Read `SOUL.md` to understand persona and tone.
2. Read `RULES.md` for guardrails and mandatory checks.
3. Read `SKILL.md` to see which reusable skills are relevant.
4. Read `TOOLS.md` before choosing how to inspect or modify files.
5. Read `WORKFLOW.md` before planning or executing work.
6. Read `MEMORY.md` for project-specific history and gotchas.

Keep edits local to the role that owns the task. If a change crosses roles, use the least invasive path and do not rewrite unrelated context.
