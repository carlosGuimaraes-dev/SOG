# Skills Disponíveis — Dev Senior

Este arquivo lista as skills reutilizáveis à disposição deste agente.
Para usar uma skill, leia seu SKILL.md antes de implementar.

---

## Playwright Scraper
**Use quando:** automatizar interação com PJe, SISTJWEB ou outros sistemas judiciais; fazer scraping de dados processuais; capturar screenshots de evidência.
**Arquivo:** `.kimi/skills/playwright-scraper/SKILL.md`
**Prioridade:** ALTA (domínio do projeto)

## FastAPI Backend
**Use quando:** criar ou modificar endpoints, schemas Pydantic, autenticação JWT, routers, middlewares ou documentação OpenAPI.

**Prioridade:** ALTA

## SQLite Patterns

**Arquivo:** `.kimi/skills/sqlite-patterns/SKILL.md`

## PDF Processor

**Prioridade:** ALTA (domínio do projeto)

**Prioridade:** MÉDIA

## Como usar uma skill

1. Antes de implementar, verifique se há uma skill relevante nesta lista
2. Leia o SKILL.md da skill com `ReadFile`
3. Aplique os padrões e exemplos no código que está escrevendo
4. Siga os anti-patterns listados para evitar armadilhas conhecidas
